💻 System Level Integration

HTS operates as a robust system add-on, serving as a drop-in replacement for the standard Linux Date command. Administrators utilize the hts-time command to query the core logic directly, bypassing local timezone conversion for raw Epoch data.
user@linux:~/s $ hts-time
> BASE REFERENCE: 2023 AD
> EPOCH DELTA: +3 YRS
> HTS OUTPUT: 1A40003
user@linux:~/s $ hts-time --sync
> LATENCY: 0.0004ms [OK]
user@linux:~/s $
