System Features

🕰️ Core Timekeeping
The Human Time System Engine: Native implementation of the infinite, cyclical deep-time calendar (50,000-year Epochs).
Live HTS HUD: Persistent, highly visible HTS clock overlay across the application.
Converters & Timezones: Dedicated modules for translating standard Gregorian time into HTS and managing global offsets.
🖥️ Dual Architecture (CLI & GUI)
Terminal Native (CLI Mode): Typing `hts-time` in the terminal instantly prints the current HTS timestamp and cleanly exits, perfect for scripting or quick reference.
Immersive GUI: Launching from the desktop icon (or with `--gui`) boots a fully isolated, hardware-accelerated GTK/WebKit application.
Surgical Terminal Silencer: A completely clean stdout terminal profile when the GUI boots, keeping backend operations totally invisible to the user.
🎨 Theming & Customization
HTML Theme Engine: Fully modular control panels. Swap between standard decks (VHS, Industrial, Starship, Leopard, etc.) or import your own standard HTML files.
Faceplate Armor System: Apply custom images to the dashboard panel. Includes a long-press context menu to rename, delete, or reset to default.
UI Calibration Engine: Press `Ctrl+C` to unlock the HUD and use the arrow keys to physically raise or lower the control panel to perfectly align with your background video. Remembers your offset per-theme.
🎬 Media Vault & Playback
Isolated Flatpak Vault: A secure, sandboxed media repository specifically for your background ambiance and large video files.
MicroHTTP Streaming Backend: Bypasses WebKit restrictions using a custom C-based `libmicrohttpd` server, allowing for flawless, chunked streaming of massive video files without crashing the browser.
Hybrid Resumable Autoplay: Short ambiance videos loop automatically. Large movies and long videos automatically pause and remember the exact second you left off.
Cinema Mode: Instant fullscreen toggle with UI blackout, backed by global hotkeys (Spacebar for Play/Pause, Up/Down Arrows for Volume) that work no matter where you click.
PulseAudio Integration: Direct communication with system audio to prevent muted playback bugs.
🛡️ Security & Immersive Modes
Secure Screensaver Mode: Launch with `--screensaver` to boot an immersive background lock screen.
PIN Protection: Intercepts clicks and keypresses to bring up a neon security overlay requiring a user-defined PIN to return to the system.
Backdrop Blackout: Toggle between frosted glass blurs or total blackouts for the area behind the control panel.
🧬 Developer Tools ("God Mode")
Theme Inspector: A built-in structural analysis tool that scans imported HTML themes to verify they have the correct CSS/div requirements.
Logic DNA Injector: Automatically injects the HTS Javascript Protocol (the "Brain") into imported third-party HTML files so they can seamlessly control the app without manual coding.
Media Doctor: Live diagnostic clinic to verify Codec DNA (like VP9 stability) and monitor network stream health.
