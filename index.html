The Storcke Human Time System

Welcome to the official Flatpak repository for the Human Time System. This repository hosts an infinite, cyclical calendar designed for deep time, tracking Epochs of 50,000 years starting from A0.

Installation Instructions

To install the HTS application on Fedora, Ubuntu, or any Flatpak-enabled Linux distribution, open your terminal and run the following commands:

1. Add this custom repository to your system:

flatpak remote-add --user --if-not-exists --no-gpg-verify storcke64-hts https://storcke64.github.io/hts-time/

2. Install the application:

flatpak install --user storcke64-hts com.storcke64.hts_time

How to Run

The Human Time System is driven by the core hts-time command. You can access both the visual interface and the command-line tool depending on how you launch it:

Graphical Interface (GUI)

If you prefer a visual experience, the easiest way is to click the HTS Time System icon in your desktop's application menu.

To launch the GUI from your terminal, you must use the hts-time --gui command. Through the Flatpak wrapper, it looks like this:

flatpak run com.storcke64.hts_time --gui

Command Line Interface (CLI)

If you want to use the terminal interface, you use the standard hts-time command without any flags. Through Flatpak, run:

flatpak run com.storcke64.hts_time

This will output the current standard date followed by the HTS deep-time date format. The output looks like this:

Wed Feb 25 22:40:25 CST 2026 HTS A40003
