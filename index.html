The Storcke Human Time System

Welcome to the official Flatpak repository for the Human Time System. This repository hosts an infinite, cyclical calendar designed for deep time, tracking Epochs of 50,000 years starting from A0.

Installation Instructions

To install the HTS application (GUI and CLI) on Fedora, Ubuntu, or any Flatpak-enabled Linux distribution, open your terminal and run the following commands:

1. Add this custom repository to your system:

flatpak remote-add --user --if-not-exists storcke64-hts https://storcke64.github.io/hts-time/

2. Install the application:

flatpak install --user storcke64-hts com.storcke64.hts_time

How to Run

Once installed, you can launch the GUI from your application menu, or run it directly from the terminal:

flatpak run com.storcke64.hts_time
Note: This web page exists to serve Flatpak repository data. You do not need to download any files directly from your browser. Please use the terminal commands provided above.
