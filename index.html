The Storcke Human Time System

Welcome to the official Flatpak repository for the Human Time System. This repository hosts an infinite, cyclical calendar designed for deep time, tracking Epochs of 50,000 years starting from A0.

Installation Instructions

To install the HTS application on Fedora, Ubuntu, or any Flatpak-enabled Linux distribution, open your terminal and run the following commands:

1. Add this custom repository to your system:

flatpak remote-add --user --if-not-exists --no-gpg-verify storcke64-hts https://storcke64.github.io/hts-time/

2. Install the application:

flatpak install --user storcke64-hts com.storcke64.hts_time

How to Run

The Human Time System includes both a visual interface and a command-line tool. Choose how you want to interact with it below:

Graphical Interface (GUI)

The easiest way to launch the calendar is to find the HTS Time System icon in your desktop's application menu and click it.

You can also launch the GUI directly from your terminal by passing the --gui flag to the base command:

flatpak run com.storcke64.hts_time --gui

Command Line Interface (CLI)

If you prefer to interact with the system via the terminal, simply run the base command without the flag. This executes the core hts-time logic inside the sandbox:

flatpak run com.storcke64.hts_time
Note: This web page exists to serve Flatpak repository data. You do not need to download any files directly from your browser. Please use the terminal commands provided above.
